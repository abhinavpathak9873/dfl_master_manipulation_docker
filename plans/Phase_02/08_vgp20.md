# VGP20 integration

## Goal

Add VGP20 as a first-class tool with its actual geometry, vacuum behavior,
feedback, and real/simulated adapters.

## Task-script payoff

A task selects `gripper="vgp20"` and uses the small gripper API while retaining
direct access to VGP20-specific settings and diagnostics.

## Work

1. Verify official documentation, installed communication route, controller/IO,
   commands, feedback, and safety behavior.
2. Add mount, TCP, collision, payload, and hose/tool geometry for M1013/H2515
   compatibility.
3. Implement open/release, close/grip, stop, timeout, suction/power feedback, and
   useful result mapping.
4. Keep VGP20-specific parameters explicit rather than forcing VGC10 semantics.
5. Add Gazebo and Genesis approximations and state their limits.
6. Define commissioning checks for identity, mounting, TCP, payload, IO,
   pressure, release, stop, and disconnect.
7. Test success/no-object/leak/loss-of-pressure/timeout/disconnect paths.

## Acceptance

- VGP20 works through the shared minimum API and exposes required specific
  methods/status.
- Robot descriptions and collision geometry are valid for declared profiles.
- Simulation and real behavior differences are clear.
- Errors identify the selected tool, mode, command, and missing feedback.

## Non-goals

Copying VGC10 behavior without hardware evidence or hiding vendor diagnostics.
